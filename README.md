# FiiO M15 Apple Music Fix — V1

让 FiiO M15 上的 Apple Music 能登录、能播放，也不再把原厂机器误报为 Root。

希望这份补丁能让拥有 FiiO M15 的朋友多一个在线流媒体的选择，让手里的播放器继续陪大家听喜欢的音乐。希望大家喜欢，也欢迎分享使用体验。

**适用范围：FiiO M15，原厂固件 1.0.4，Android 7。** M15S、其它型号及其它固件未验证，不适用本包。

这是无偿的社区兼容修复，与 FiiO、Apple 无隶属关系。本次只发布补丁和配套说明，不单独公开开发源码；安装运行必需的脚本和版权材料保留。

**补丁附件尚未公开下载，分发方式正在整理。** 以下为已验收版本的使用说明。

## 修复内容

| 问题 | 修复位置 | 处理方式 |
| --- | --- | --- |
| 音轨初始化异常、播放无声 | M15 系统 | 修复音轨初始化和音轨互相干扰的问题 |
| 原厂系统被 Apple Music 误报 Root | M15 系统 | 校正系统构建标签，保留 APP 原有检测逻辑 |
| Apple Music 在 Android 7 上登录失败 | Apple Music 4.9.7.2 | 补齐设备初始化，仅修登录，不修改播放器 |

**系统补丁与登录补丁需要分别安装。刷系统包不会自动修改 Apple Music。**

音频兼容修复位于 M15 基于 AOSP 的系统音频框架中：静态音轨容量恢复 Android 7 AOSP 原有规则，另一处局部处理避免未播放的小音轨干扰当前输出，同时保留原厂采样率／格式协商。没有移植 MIAD01 的系统库，也没有整体替换音频框架。上游归属与许可见 [版权与使用声明](NOTICES.md)。

## 系统安装

1. 解压 `M15-system-compat-V1-1.0.4-2026-10-01-kit.zip`。
2. 将里面的 **install、restore 两个 ZIP** 一起复制到外置 SD 卡，保留还原包。
3. 进入 M15 原厂 Recovery，选择 **Apply update from SD card**。
4. 选择 `M15-install-system-compat-V1-1.0.4-2026-10-01.zip`。
5. 出现 `M15_V4_REPAIR_THREE_FILES_PASS` 后，选择 **Reboot system now**。

外层 kit 先解压；里面两个可刷 ZIP 不要解压。不要选择 **Wipe data/factory reset**。

对外版本叫 **V1**。Recovery 中的 `V4` 是内部验收标记，不影响使用。

## 原厂还原

同样进入 Recovery，从 SD 卡选择：

`M15-restore-original-system-V1-1.0.4-2026-10-01.zip`

看到 `M15_V4_RESTORE_THREE_FILES_PASS` 后重启。

还原包只恢复修改涉及的三个系统文件，不执行恢复出厂设置，也不更换 APP 或清除账号和下载数据。原厂构建标签恢复后，Apple Music 的 Root 误报也会恢复。

## Apple Music 登录补丁

已验收版本：**Apple Music 4.9.7.2 / versionCode 1472**。

本地已完成 Windows 安装工具：连接 M15、授权 USB 调试后安装三个配套分包。公开分发方式尚未定稿，暂不提供完整修改 APK 下载。

修改版使用项目测试签名，**不是 Apple 原签名**。从官方版切换时通常需要卸载旧版，卸载会清除 APP 账号、设置和下载内容；同签名版本可以尝试覆盖。安装工具不会自动卸载或清数据。

## 影响范围

- 未增加 SRC，也未更改原有重采样配置。
- 构建标签改为 `release-keys`，不会让设备取得 Root，也不会重新签名固件。其它 APP 对该标签的判断可能变化。
- 原厂 fingerprint 保留；Recovery 顶部仍显示 `test-keys` 是预期现象。
- 已确认 FiiO Music、Apple Music 实际播放正常。其它输出接口、DSD/MQA、逐位透明度及长期稳定性未全部验证。
