# 常见问题

## 系统包和登录补丁要都装吗？

当前完整验收组合是系统 V1 加 Apple Music 4.9.7.2 登录修复。系统包解决音频兼容和 Root 误报，不会自动修改 APP 或补登录初始化。

## 为什么不是直接用官方 APP？

官方版仍有已确认的 Android 7 初始化兼容问题。修改版仅补登录初始化，播放器和 Root 检测代码保持原版，但已重新签名，不能称为 Apple 原签名 APK。

## 可以直接覆盖官方 APP 吗？

官方签名与项目测试签名不同，通常需先卸载；卸载会清除账号、下载和设置。工具不会自动卸载，同签名版本可以尝试覆盖。

## 改成固定 48kHz 或新增 SRC 了吗？

没有强制全部输出为48kHz，也未新增SRC或更改重采样配置。已经观察到Apple Music以44.1kHz播放。

## 帧数是不是固定改成某个值？

没有给所有音轨设置统一帧数。静态音轨容量按实际缓冲区确定，流式音轨仍保留原有缓冲策略。

## release-keys 就代表官方正式签名吗？

不能。只是构建标签改变，实际固件签名与Root权限不变。其它检测逻辑仍可能依据其它信息判断设备。

## 为什么 Recovery 顶部还是 test-keys？

原厂fingerprint没有整体替换，因此该显示是预期情况。

## 还原会清空机器吗？

不会执行恢复出厂设置，只写回三个原厂系统文件，不还原APP和已丢失数据。原厂构建标签恢复后，Apple Music的Root误报也会恢复。

## 其它型号也能刷吗？

不能。本包针对M15固件1.0.4，未知系统文件会拒绝安装。请勿删除机型或文件校验。

## 下载在哪里，为什么没有完整修改 APK？

系统修复与原厂还原包已在 [V1 发布页](https://github.com/RagnarokChan/fiio-m15-apple-music-fix/releases/tag/V1) 提供，下载 kit 后先解压，真正可刷的是里面的 install、restore 两个 ZIP。

Apple Music 登录修复已完成本地使用验收，但本次不公开完整修改 APK；登录补丁的公开分发形式另行整理。系统包不能代替登录补丁。

GitHub 自动显示的 Source code ZIP/TAR 只是仓库说明和版权文件的归档，不是可刷安装包，也不包含开发源码。
